# நமது நிலை — source-level correction application ledger

## Purpose

This ledger consolidates the **175 confirmed discrepancies** found during the first full word-by-word visual-fidelity pass of `ACL-CPL_01726_நமது_நிலை.pdf`.

The detailed `First pass / Scan / Correction` evidence remains in the visual-fidelity audit files. This ledger records where each numbered correction was applied in the corrected source-level transcription.

The corrected transcription remains **source-level**. It is not yet a dated/House-specific canonical speech transcript because the edition does not securely expose the Assembly/Council split or Kalaignar's exact reply dates.

This is **not discrepancy 176**: it is a correction to an error introduced during consolidation, not a newly discovered error in the user's original first-pass transcription.

The neighboring audit-entry-162 form remains separately applied in its actual sentence:
