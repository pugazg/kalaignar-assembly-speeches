## Archival scope

This folder is the reader-facing speech/translation location for the `நமது நிலை` source package.

The booklet is an **edited two-House compilation**, not one continuous verbatim Assembly speech. Its two printed units contain material associated with replies delivered in the Tamil Nadu Legislative Assembly and Legislative Council. This folder preserves the booklet **as printed** rather than reconstructing separate House transcripts.

## Non-negotiable textual-authority rule
