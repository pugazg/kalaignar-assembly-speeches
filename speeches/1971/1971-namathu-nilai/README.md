## Archival scope

This folder is the reader-facing speech/translation location for the `நமது நிலை` source package. The booklet is an **edited two-House compilation**, not one continuous verbatim Assembly speech, so this folder preserves the booklet **as printed** rather than reconstructing separate House transcripts.
